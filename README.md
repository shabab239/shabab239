## 🔭 What I work on

- 🏫 **isCool / SchoolBell**: a school-management ERP (admissions, exams and results, fees, attendance, SMS and push notifications) used by real institutes. Java, Spring MVC, MariaDB, with a Vue web app and a Flutter mobile app.
- 📱 **Flutter apps**: a personal ledger app on Firebase, and a matrimonial app with a Dockerised Java server.
- 🏝️ **WindyLand**: a free, open-source Dynamic-Island-style notch for Windows, written in Rust.
- 🧾 **Estate and consulting ERPs**: property management and engineering-consultancy systems for clients.
